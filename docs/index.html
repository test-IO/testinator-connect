Setup

Three steps to connected

01

Install & launch

Download the build for your OS, install it like any other desktop app, and launch it. No admin rights needed on Windows.

02

Connect the app

In your installation: avatar → User Settings → Agentic QA Connect → Connect app. One click hands the app a one-time code — nothing to copy by hand.

agentic-qa-connect://
03

Run sessions

The paired row turns ● Online. Start a session from your installation and it runs on this machine.
